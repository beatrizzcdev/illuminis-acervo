# 📚 Illuminis

**Seu acervo, suas histórias, seu universo.**

O Illuminis é um acervo bibliotecário digital criado para explorar, pesquisar e organizar livros de forma simples, intuitiva e agradável.


## 🎨 Sobre o projeto

O Illuminis foi desenvolvido como projeto acadêmico do curso de Análise e Desenvolvimento de Sistemas.
